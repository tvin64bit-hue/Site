# Архив фотографий

Оригинальные снимки ресторана из старого сайта на Tilda, которые
не используются ни на одной странице нового сайта. Лежат здесь на
всякий случай: скачать их заново неоткуда, если боевой сайт на Tilda
отключат.

Если они не нужны — папку можно удалить целиком, на работу сайта
это никак не влияет.
