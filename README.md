# Сайт ресторана «Итальянка»

Сайт italianca.ru, переписанный с нуля без Tilda. Чистые HTML, CSS и
ванильный JavaScript: ни фреймворков, ни сборщиков, ни jQuery, ни внешних
скриптов. Открывается двойным щелчком по `index.html` и кладётся на любой
статический хостинг как есть.

## Структура

```
index.html                        главная
bantet-italyanca-chelyabinsk/     банкеты
politica_clb/                     политика конфиденциальности
soglasie_all/                     согласие на обработку данных
work_soglasie/                    согласие (соискатели)
drugie_soglasie/                  согласие (третьи лица)

assets/css/style.css              единственный файл стилей
assets/js/app.js                  меню, вкладки, модалки, формы
assets/img/                       фотографии, сканы меню, иконки
assets/fonts/                     шрифт Roboto (см. README внутри)
data/specials.js                  тексты спецпредложений
```

Адреса страниц остались прежними — старые ссылки и позиции в поиске
не сломаются.

## Как посмотреть

Достаточно открыть `index.html` в браузере. Либо поднять локальный сервер:

```
python3 -m http.server 8000
```

## Что осталось от старого сайта

Все тексты, фотографии, сканы меню и юридические документы перенесены
с боевого сайта дословно. Сохранены фирменные цвета (бордовый `#912f32`),
скруглённые кнопки, порядок и содержание разделов.

Изменилась только техническая часть: вместо абсолютного позиционирования
zero-блоков Tilda — CSS Grid и Flexbox, поэтому на телефонах вёрстка ведёт
себя заметно лучше. Вес страницы упал примерно с 160 КБ HTML плюс два
десятка внешних скриптов до 28 КБ HTML, 20 КБ CSS и 8 КБ JS.

Счётчики аналитики (Яндекс.Метрика, Top.Mail.Ru, пиксель ВК) не переносились.

## Оформление и эффекты

- заголовки набраны антиквой (Playfair Display, запасная — Georgia);
- hero с медленным наездом камеры и стрелкой «листайте»;
- бегущая лента под первым экраном, останавливается при наведении;
- секции проявляются при прокрутке, цифры набегают счётчиком;
- две фотоврезки во всю ширину с параллаксом;
- меню — слайдер со стрелками, точками и свайпом, клик открывает
  страницу крупно с листанием стрелками и клавишами;
- галерея выложена мозаикой;
- на телефоне снизу закреплена панель «Забронировать / Позвонить».

Всё движение отключается, если в системе включена настройка
«уменьшить движение» (`prefers-reduced-motion`).

## Заглушки: что пока не работает по-настоящему

**Формы** — бронирование стола, заявка на банкет и анкета соискателя.
Поля, валидация и сообщения работают, но данные никуда не уходят: заявка
только пишется в консоль браузера. Реальная отправка включается одной
правкой — функция `sendLead()` в `assets/js/app.js`, там же в комментарии
готовый пример запроса. Больше ничего менять не нужно.

**Карта** в разделе «Как нас найти» — не интерактивная: это плитка со
ссылкой, открывающая Яндекс.Карты в новой вкладке. Так страница не тянет
тяжёлый сторонний скрипт.

**Доставка** работает по-настоящему: кнопки ведут на страницу ресторана
в Яндекс.Еде. Ссылка «Выиграть приз» тоже настоящая.

## Что нужно заполнить

**Спецпредложения.** Раздел на главной сейчас скрыт: тексты акций на
старом сайте подгружались из ленты Tilda и в выгрузку не попали. Как
только впишете их в `data/specials.js`, раздел появится сам:

```js
window.SPECIALS = [
  { title: 'Название акции',
    text:  'Описание',
    note:  'Условия',                  // необязательно
    image: 'assets/img/имя.jpg' }      // необязательно
];
```

**Шрифт Roboto.** Три файла нужно положить в `assets/fonts/` — подробности
и ссылки в `assets/fonts/README.md`. Пока их нет, работает запасной шрифт.

**Режим работы** на главной и на странице банкетов отличается: на главной
«Пн-чт, вс 12.00-00.00, Пт, сб 12.00-02.00», на банкетной «Пн-чт, вс
с 12:00 до 22:00, Пт-сб с 12:00 до 20:00». Так было на боевом сайте —
оба варианта перенесены как есть, поправьте тот, что неверен.
